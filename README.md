# Variant Finder

Aplicação web para busca e de variantes genômicas

## Recursos

- Busca por genes e rsIDs.
- Suporte a GRCh37 e GRCh38.
- Informações de cromossomo, posição, alelos, rsID e consequência.
- Dados clínicos, como significância, condição e herança.
- Filtros e ordenação de variantes.
- Busca de artigos científicos.
- Lista de variantes salvas.
- Exportação para Excel.
- Links para bases como ClinVar, dbSNP, PharmGKB, Ensembl e GeneCards.

## Fontes que a aplicação busca

- Ensembl
- MyVariant.info
- ClinVar
- dbSNP
- MyGene.info
- PanelApp
- PubMed
- Europe PMC
- OpenAlex
- Crossref
- Semantic Scholar
